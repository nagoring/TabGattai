# Chrome ウェブストア 掲載情報（日本語）

デベロッパーダッシュボードに貼り付ける文面です。

## ストアの掲載情報

**アイテム名**（manifest の `extName` から自動で入ります）
TabMerge - タブをまとめて保存

**概要**（manifest の `extDescription`、132文字以内）
開いているタブをワンクリックで保存・復元。重複したURLは最新の保存グループへ自動でまとめます。データはブラウザ内にのみ保存。

**カテゴリ**：仕事効率化（Productivity）
**言語**：日本語（英語も追加）

**説明**

```
TabMerge は、開いているタブをワンクリックでまとめて保存し、必要なときに復元できるシンプルなタブ管理ツールです。
タブを開きすぎてブラウザが重くなったとき、作業をいったん区切りたいときに便利です。

■ 最大の特徴：重複URLは最新のグループへ自動で移動
同じページを何度も保存しても、一覧に同じURLが並ぶことはありません。
すでに保存済みのURLを再び保存すると、古いグループからそのURLを取り除き、最新の保存グループへ移動します。
古いグループが空になった場合は自動で削除されるので、一覧がいつもすっきり保たれます。

■ 主な機能
・ツールバーのアイコンをクリックするだけで、現在のウィンドウのタブを保存して閉じます
・保存したタブは日時ごとのグループで一覧表示（タイトル・ファビコン・URL）
・タブをクリックすると新しいタブで開き、一覧から削除（設定で残すことも可能）
・グループ単位で「すべて復元」「名前の変更」「URLをコピー」「削除」「折りたたみ」
・保存済みのすべてのタブを、タイトルとURLから横断検索
・JSON ファイルへのエクスポート／インポート（インポート時も重複を自動統合）
・ライト／ダーク／OS設定に合わせたテーマ
・日本語／英語に対応

■ 保存の対象
・通常のWebページ（http / https / file）のタブが対象です
・chrome:// などのブラウザ内部ページは保存しません
・固定タブは初期設定では保存しません（設定で変更できます）

■ プライバシー
・保存したURL・タイトル・設定は、お使いのブラウザ内（chrome.storage.local）にのみ保存されます
・外部サーバーへの送信、アクセス解析、広告は一切ありません
・アカウント登録は不要です

■ ヒント
・保存せずに一覧だけを開きたいときは、ツールバーのアイコンを右クリックして「オプション」を選択してください
```

## プライバシーへの取り組み（Privacy practices）

**単一用途の説明**
```
開いているタブを保存・復元するタブ管理ツールです。保存時に重複したURLを最新の保存グループへ統合します。
```

**権限が必要な理由**

| 権限 | 記入例 |
| --- | --- |
| tabs | 現在のウィンドウで開いているタブのURLとタイトルを取得して保存し、保存したタブを閉じ、復元時に新しいタブで開くために使用します。 |
| storage | 保存したタブの一覧と設定を、ユーザーのブラウザ内（chrome.storage.local）に保存するために使用します。 |
| favicon | 保存一覧に各サイトのアイコンを表示するために、Chrome が端末内に保持しているファビコンを参照します。ネットワーク通信は行いません。 |

**リモートコードの使用**：いいえ（すべてのコードはパッケージに同梱）

**データの使用状況**
- 本拡張機能は保存したタブの URL を扱います。ただし、データはすべて端末内に保存し、外部へ送信しません。
- 該当するデータの種類として「ウェブ履歴」を選ぶかどうかは、ダッシュボード上の定義を確認して判断してください。迷う場合はチェックしておくと安全です。
- 次の3項目に同意（チェック）します：
  - 承認されている用途以外で、ユーザーデータを第三者に販売、転送しない
  - アイテムの単一用途と関係のない目的で、ユーザーデータを使用、転送しない
  - 信用力の判断や融資目的で、ユーザーデータを使用、転送しない

**プライバシーポリシーの URL**
```
https://github.com/nagoring/tabmerge/blob/main/docs/privacy-policy.ja.md
```
（リポジトリが公開されている必要があります。非公開の場合は GitHub Pages などで公開してください）
