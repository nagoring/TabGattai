# TabGattai プライバシーポリシー

最終更新日: 2026年11月2日

TabGattai（以下「本拡張機能」）は、Google Chrome 用のタブ管理拡張機能です。本ポリシーは、本拡張機能が取り扱う情報とその取り扱い方法を説明します。

## 1. 取り扱う情報

本拡張機能は、ユーザーがツールバーアイコンをクリックしてタブを保存したときに、次の情報を取り扱います。

| 情報 | 用途 |
| --- | --- |
| 保存対象タブの URL | 保存一覧の表示、タブの復元、重複 URL の統合 |
| 保存対象タブのページタイトル | 保存一覧の表示、検索 |
| 保存日時・グループ作成日時 | 保存グループの表示・並び替え、重複統合時の新旧判定 |
| ユーザーが付けたグループ名 | 保存グループの表示 |
| 設定値（固定タブの扱い、復元時の削除、テーマ、言語） | 本拡張機能の動作設定 |

本拡張機能は、Web ページの本文・フォーム入力内容・Cookie・閲覧履歴・パスワード・個人を特定する情報を読み取りません。Web ページ内で動作するスクリプト（コンテンツスクリプト）も使用していません。

## 2. 保存場所

上記の情報はすべて、ご利用中のブラウザ内のローカル領域（`chrome.storage.local`）にのみ保存されます。Chrome の同期機能（`chrome.storage.sync`）は使用しません。

## 3. 外部送信

本拡張機能は、上記の情報を含むいかなるデータも、開発者または第三者のサーバーへ送信しません。

- 外部サーバー・データベースを使用しません
- アクセス解析ツールを使用しません
- 広告を表示しません
- ユーザー登録・ログインを必要としません
- 外部から JavaScript などのコードを読み込みません

ファビコン（サイトのアイコン）は、Chrome が端末内に保持しているキャッシュから Chrome の `favicon` 機能を通じて表示しており、本拡張機能がネットワーク通信を行うことはありません。

なお、ユーザーが保存済みタブを「復元」した場合、ブラウザがそのページを通常どおり開くため、当該 Web サイトとの通信が発生します。これは通常のブラウジングと同じであり、本拡張機能がデータを送信するものではありません。

## 4. エクスポート・インポート

ユーザーが「JSON にエクスポート」を実行した場合、保存データ（URL・タイトル・グループ名・日時・ID）を含む JSON ファイルがユーザーの端末にダウンロードされます。このファイルの管理はユーザーご自身の責任となります。インポートしたファイルの内容は検証のうえ、ブラウザ内にのみ保存されます。

## 5. 権限について

| 権限 | 理由 |
| --- | --- |
| `tabs` | 現在のウィンドウのタブの URL・タイトルを取得して保存し、保存後にタブを閉じ、復元時にタブを開くため |
| `storage` | 保存データと設定をブラウザ内に保存するため |
| `favicon` | 保存一覧に各サイトのアイコンを、Chrome の端末内キャッシュから表示するため |

ホスト権限（特定サイトへのアクセス権限）は要求しません。

## 6. データの削除

- 保存一覧の「×」ボタンや「グループを削除」で個別に削除できます。
- 本拡張機能をアンインストールすると、ブラウザ内に保存されたすべてのデータが Chrome によって削除されます。

## 7. 第三者への提供

本拡張機能は情報を収集・送信しないため、第三者へ提供・販売することはありません。

## 8. ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改訂します。取り扱う情報や外部送信の有無に関わる重要な変更を行う場合は、拡張機能の更新内容でお知らせします。
